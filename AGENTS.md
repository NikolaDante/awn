# Repository Instructions

All AWN frontend and UI work must follow docs/AWN-DESIGN-CONSTITUTION.md. Adding functionality does not authorize changes to the established AWN design system.

AWN has one permanent user-facing testing URL: `https://awn-preview-awn4.vercel.app`. After a fresh immutable Preview is verified, repoint this same alias to it and give the user only the stable URL; never ask the user to move between immutable Preview hosts.
